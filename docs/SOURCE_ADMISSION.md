# 中文采集来源准入记录

本文件记录中文锚点采集来源的准入状态。准入结果用于控制 `CN_SOURCE_LIST`；代码中的来源适配器存在，不等于来源已获准用于生产。

## 当前决定

| 来源 | 许可/授权 | 稳定性与限流 | 相关性 | 当前模式 |
|---|---|---|---|---|
| 淘宝搜索建议 (`taobao_suggest`) | 当前项目已使用的基线来源；上线前仍需运营方确认账户与适用条款 | 以 HTTP 状态、响应变化、超时、429 和来源快照监控；请求串行，默认间隔 0.5 秒 | 中文电商搜索建议 | 生产 |
| Alibaba 官方推词 (`alibaba_keyword_recommend`) | [官方文档](https://developer.alibaba.com/docs/api.htm?apiId=63333)标注需要授权，并要求聚石塔内调用；请求要求产品线上下文 | 已知为签名授权接口，需确认授权账户、产品线和业务上下文后才能审查实际限流及稳定性 | 广告计划关键词建议，不等同于通用全站搜索建议 | 关闭；未进入 shadow 或生产 |
| 京东搜索建议 | 仓库既有运行记录显示接口已返回反爬 HTML，不能作为可靠 JSON 来源 | 未满足稳定性条件 | 原本相关 | 不再接入 |

目前没有新的来源通过完整准入检查，因此 `CN_SOURCE_LIST` 保持 `taobao_suggest`。这是一项明确的 fail-closed 决定：未经确认的条款、缓存权利或接口限制不会由代码默认推断。也没有对关闭来源发起 shadow 请求。

## 准入条件

每个候选来源在加入 `CN_SOURCE_LIST` 前，需有记录支持以下各项：

1. 适用于 Joytag 商业用途的服务条款、授权范围及可保留/缓存字段。
2. 官方接口或可验证的稳定协议、允许的请求频率、429 与 `Retry-After` 行为。
3. 在目标中国商品类别中的词汇相关性抽样结果。
4. 单次响应内的排名/热度归一化方案，以及响应变化和故障监控。
5. 七天 shadow 运行结果：成功率至少 95%，429 比例不高于 1%，为锚点带来的未见候选至少增加 10%。

通过准入的来源默认先进入 shadow；shadow 结果仅用于比较，不参与锚点入库。经过七天指标与合规复核后，才可由维护者将其加入生产来源配置。当前来源适配器只会运行 `production_eligible=true` 的来源，Alibaba 接口在授权及上下文未确认前仍为关闭状态。
