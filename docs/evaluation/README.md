# Joytag 模拟测评集 v0.1

创建日期：2026-10-16。用途是设计 Jev、现有 LLM 和人工审核的**离线对照试验**；所有商品、锚点状态和推荐候选均为模拟，不来自生产词库或真实订单。当前文件不是人工标注的真值集，也不能用来声称任何模型已经提升质量。

## 文件和范围

| 文件 | 数量 | 用途 |
| --- | ---: | --- |
| `synthetic_tag_cases.jsonl` | 48（每国 8） | 采集词分流和三类语义判断；DE/FR/NL/UK/IT/ES 各有普通描述、需要商品证据的声明、无锚点、环保词和碳中和词。 |
| `synthetic_recommend_cases.jsonl` | 12（每国 2） | 在固定候选内评价推荐相关性；家居和时尚各 1 例。 |

每行是一个 UTF-8 JSON 对象，`id` 唯一。词的本地语言表达由模型拟写，尚需目标语母语者复核。商品类目也只是固定测试字段，不代表正式类目体系。

### 标签样本字段

- `anchor_fixture`：**注入的**锚点检索结果；不是对真实 GTE/Qdrant 能否匹配的断言。若要评测锚点召回，须另建含真实候选锚点、相似度和人工匹配标签的数据集。
- `rule_fixture`：注入的规则结果；`null` 表示在隔离测试中假定无规则命中，不能直接等同于当前生产规则文件。非空时采用仓库现有规则 ID。
- `expected_gate`：在上述两个 fixture 下，当前流程应到达的关口：`model_assess`、`pending_no_anchor`、`blocked`。它只检验程序分流，不是法律结论。`model_assess` 不代表最终批准。
- `hypothesis`：`allow`、`review`、`block`。这是**供标注者讨论的模拟语义判断**，不可计为真实准确率或直接写入 `local_tags`。
- `scenario`：拟定该判断的理由或缺少的证据；`review_priority` 用来安排复核顺序，不是模型置信度。

刻意保留 `expected_gate=blocked`、`hypothesis=review` 的环保样本。例如，现有内置规则会匹配 `klimaneutral`，但词本身不能说明该声明是否基于碳抵消；有关商品信息和证据需要单独核查。这类样本用于发现规则可能过宽，不应直接计作“模型判错”。`UK` 样本还要按英国法单独复核：欧盟 Directive (EU) 2024/825 不因产品面向英国就自动适用，英国环境声明参考 CMA Green Claims Code。

### 推荐样本字段

- `candidates` 内的 `grade`：人工拟定的相关性等级，0=无关、1=部分相关、2=直接相关；所有候选**假定**已通过合规过滤。本集不能评测候选入库的合规性。
- `illustrative_vector_order`：为演示指标计算而**人为设定**的顺序；不是当前 GTE 向量模型的输出，也不能据此声称精排优于线上基线。
- `top_k` 固定为 2。评测 Jev 或现有 LLM 时只允许选择这四个候选，未列入的标签按非法输出记录。

## 建议的对照方法

1. **冻结输入**：记录数据集版本、模型确切版本（避免仅用 `latest`）、提示词、规则版本、锚点 fixture、候选集和运行时间。所有方案使用相同输入。不要访问生产 Qdrant，也不要把模拟数据写进业务集合。
2. **先校验门控**：对标签集验证 6 个无锚点普通词只能进入待审核、12 个规则词进入拦截。这个检查针对当前流程，与 Jev 的语义能力分开统计。
3. **再评语义**：只将 `expected_gate=model_assess` 的 30 个样本用于现有 LLM 与 Jev 的三类判断比较。无锚点和规则命中词可以作为模型旁路一致性检查，但不能把模型结果用于推翻门控。
4. **先做人工标注**：至少由一名懂目标市场语言的审核员和一名熟悉相应商品/法规的审核员独立标注；出现分歧时记录双方理由并裁决。对材质、有机、环保和疾病宣称，补齐商品资料及证明；缺证据时保留 `review`。人工确认后另存真值文件，不覆盖本模拟集。
5. **再算指标**：三类混淆矩阵、误放行率（人工 `block`/`review` 被判 `allow`）、误拦截率、进入人工审核比例，并按国家及场景拆分。推荐看 Precision@2、nDCG@2、非法候选率；延迟看 p50/p95，成本按每千词或每千推荐请求计算。对 `review` 是否允许转为 `allow`，在评分前确定政策。
6. **上线门槛由团队预先确定**：例如误放行率不得高于当前流程，且各国都不能明显退化；统计上需有足够样本和不确定性区间。48/12 条只适合查接口、分流和明显问题，不足以估计真实错误率或支持生产替换。

## 扩成正式测评集

从真实审核队列、拦截记录、已批准标签和推荐请求中，按国家、类目、来源、规则命中、锚点有无分层抽样；脱敏并确认使用权限。保留采集时间、商品上下文、证明材料、审核结论和规则版本，做训练/调参集与完全隔离的保留集。若某结论依赖商品证据，而线上 Jev 输入仅有词语，应把任务定义为“转人工核查”，不能要求它猜测证明材料。

## 法规依据与边界

- [Directive (EU) 2024/825 正文](https://eur-lex.europa.eu/eli/dir/2024/825)：环保通用宣称、可持续标签和基于碳抵消的气候影响宣称的规则，需要结合具体构成要件阅读。样本中的 `hypothesis` 不是该指令下的最终法律定性。
- [UK CMA Green Claims Code](https://www.gov.uk/government/publications/green-claims-code-making-environmental-claims)：英国环境声明的官方指导；英国样本应单独复核。

本集仅供离线评测设计。法域、商品类型、证据和实际展示语境可能改变结论。
